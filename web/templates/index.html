Rivet

generative floor plan engine
GitHub Design Rules API

Design a floor plan from a room program.

Give Rivet a plot and a list of rooms. It builds an adjacency graph, searches guillotine-cut layouts with simulated annealing against a residential design rulebook, and renders the winning candidates itself — then exports each one to a real, layered DXF file.
